# MVP — Broomba

## Goal

Prove that a user can:
1. Upload a room photo
2. Get a funny, useful AI analysis back
3. Save and review their history

The emotional win: they laugh, do a 3–5 minute reset, and avoid a bigger mess or argument later.

---

## Included in MVP

### Room Check
- [ ] User can name or select a room
- [ ] User can upload a photo (file input or camera)
- [ ] User can submit for analysis

### AI Analysis Result
- [ ] Room status returned: `Stable`, `Slight Drift`, `Getting Suspicious`, `Side Quest`, or `Bro…`
- [ ] Short roast/commentary (personality-driven)
- [ ] Objective observations (what the AI actually sees)
- [ ] One tiny cleanup action
- [ ] Estimated effort: 2 min, 5 min, or 10 min

### Personality Mode
- [ ] Default: Bro Mode
- [ ] System is extensible for future modes

### History
- [ ] Room name stored
- [ ] Image reference stored
- [ ] Timestamp stored
- [ ] Status, roast, cleanup action stored

### Dashboard
- [ ] Shows latest room checks
- [ ] Shows rooms that need attention
- [ ] Shows status per room

---

## Excluded from MVP

- User accounts or authentication
- Subscriptions or billing
- Social sharing
- Notifications or push alerts
- Mobile app store deployment
- Smart-home integrations
- Household sharing / multi-user
- Gamification or streaks
- Advanced analytics
- Complex chore management
